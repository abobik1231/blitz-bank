# Блиц Банк

Портфолио-концепт сайта вымышленного банка. Проект показывает дизайн публичного банковского сайта и его интерактивные сценарии; он не представляет действующую кредитную организацию и не оказывает финансовые услуги.

## Стек

- Next.js 16 с App Router
- React 19
- TypeScript
- Tailwind CSS 4

## Запуск

Требуется Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

Для статической сборки используйте `npm run build`: готовые файлы появятся в `out/`. Команда `npm run typecheck` проверяет TypeScript.

## Публикация

GitHub Actions собирает сайт и размещает результат на GitHub Pages по адресу `https://abobik1231.github.io/blitz-bank/`. При сборке для Pages задаётся базовый путь `/blitz-bank`; локально сайт открывается без него. Прямые ссылки на страницы и обновление страницы работают благодаря статической сборке маршрутов.

## Структура

```text
app/                       маршруты App Router, общие стили и метаданные
src/components/            React-компонент публичного сайта и его взаимодействия
src/lib/legacy-content.ts  каталог страниц и сохранённые тексты продуктов
app/site.css               исходная дизайн-система и адаптивные стили
docs/Маршруты.md           карта публичных страниц
old/                       копия исходной версии; исключена из Git
```

Страницы продуктов и разделов доступны напрямую по адресу. На сайте остались публичные банковские направления, формы расчёта, поиск, меню, ответы на вопросы и информационные страницы. Регистрация и страницы личного кабинета удалены.
